# Plan: Agregar variable {{engagement}} al template de EmailJS

## Problema
El select tiene `name="engagement"` y `sendForm` lo captura correctamente, pero el template de EmailJS no tiene la variable `{{engagement}}` configurada, por eso no aparece en el email.

## Solución (en EmailJS Dashboard)

El usuario debe editar su template de EmailJS:

1. Ir a [dashboard.emailjs.com](https://dashboard.emailjs.com)
2. Ir a **Email Templates**
3. Seleccionar el template (`template_dpe1mh5`)
4. En el cuerpo del email, agregar `{{engagement}}` donde quiera que aparezca el valor del select

Ejemplo de template:
```
Nombre: {{from_name}}
Correo: {{from_email}}
Empresa: {{company}}
Tipo de proyecto: {{engagement}}
Mensaje: {{message}}
```

## No se necesita cambiar código
El componente `FormEmail2.jsx` ya tiene el campo correcto con `name="engagement"`. Solo falta configurar el template en EmailJS.
